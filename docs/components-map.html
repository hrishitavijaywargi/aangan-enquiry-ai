Why it's shaped this way

  • Code decides, AI assists. The five criteria and the pricing rule run as code (steps 6, 8, 9). Claude only fills gaps and summarises (7, 11); Vaani only listens and speaks (2a, 10a).
  • No price ever leaves the system. Price questions get pricing.md's line word for word, and the price guard checks every sentence before it is spoken (9). Vaani's own model is off, so it can't improvise one (3a).
  • Two doors, one brain. The phone line and the website simulator meet at step 4 and run identical rules.
  • A person exactly where judgment is needed. Designers price and judge fit; the studio head owns complaints; Nikhil owns the rubric and records outcomes (14).
  • Email for the record, Telegram for urgency. The designer gets one complete, searchable note; only urgent cases also ping a phone (13).

Not in scope for this build: WhatsApp and the website form. They would enter at step 4 with the same rules.
